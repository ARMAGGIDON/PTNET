# Лабораторна робота №8. Технологія ADO.NET

## Варіант 8 — Каталог дисків

Згідно з методичними вказівками: створити таблицю, заповнити її п'ятьма записами, реалізувати форму зі списком і текстовими полями, відображати записи, додавати, редагувати та видаляти їх.

**Поля:** код, тема, назва, рік видання, вартість.

## Реалізація

- Мова C#, платформа .NET 10, тип проєкту **Console Application**.
- СУБД — Microsoft SQL Server / SQL Server Express / SQL Server LocalDB.
- Доступ — ADO.NET через `Microsoft.Data.SqlClient`: `SqlConnection`, `SqlCommand`, `SqlDataReader`.
- База `PTNET_Lab08`, таблиця `dbo.Discs` створюються під час першого запуску (потрібні права `CREATE DATABASE`).
- П'ять початкових записів вставляються тільки під час створення таблиці; після видалення всіх записів вони не відновлюються автоматично.
- CRUD-запити використовують параметри SQL. `Code` — первинний ключ, `Price` — `DECIMAL(10,2)`.
- TUI резервує місце нижче попереднього виводу PowerShell та займає сталу область **96×27** у консолі розміром щонайменше **100×30**. Якщо розмір менший, показується попередження, робота призупиняється до збільшення вікна.
- У заголовку відображаються фактичний сервер та ім'я бази даних; при переході між формами перемальовується вся область; в межах форми — тільки рядки, які змінилися.
- Курсор прихований, доки користувач не перейде в режим введення в текстовому полі.

## Запуск із Rider

1. Відкрити `PTNET.slnx` у Rider і виконати NuGet Restore.
2. Переконатися, що встановлена служба SQL Server або LocalDB.
3. Запустити **Terminal** у Rider з кореня репозиторію:
   ```powershell
   dotnet run --project lab08
   ```
4. Якщо LocalDB немає, але є SQL Server Express:
   ```powershell
   $env:PTNET_LAB08_SERVER = '.\SQLEXPRESS'
   dotnet run --project lab08
   ```
5. Для власного рядка підключення можна задати `PTNET_LAB08_CONNECTION` (має вищий пріоритет за `PTNET_LAB08_SERVER`).

За замовчуванням використовується `(localdb)\MSSQLLocalDB` із Windows Authentication. `TrustServerCertificate=True` у типовому рядку дозволено лише для локального навчального SQL Server.

## Керування

**Каталог:** стрілки, PageUp/PageDown, Home/End — навігація; A — додати; E або Enter — редагувати; D або Delete — видалити; R — перечитати таблицю; Esc — вихід.

**Форма введення:** стрілки/Tab — вибір поля; Enter або F2 — режим введення; під час введення працюють стрілки, Home/End, Backspace/Delete, Ctrl+U — очистити поле; Enter — завершити введення; Esc — скасувати зміну поточного поля. Ctrl+S — записати в БД. Esc поза введенням — повернутися до каталогу.

**Підтвердження видалення:** Y або Enter — підтвердити, N або Esc — скасувати.

Терміни «форма», «список» та «текстове поле» реалізовані засобами консольного TUI, а не Windows Forms.
